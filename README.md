# HuRAG

## Project Introduction

HuRAG is an Temporal-Hierarchical-GraphRAG(TH-GraphRAG) application concentrated on interpreting laws and regulations. It is designed for organization users, not for personal usages only. It can be applied in huge organizations with complex branches of sub-organizations.

### Key Features

- Supports 4 retrieving modes including naive search, hybrid search, graph search and community-graph search.
- Retrieving documents according to the user's location in the organization.
- Parses temporal information from user query and used to choose correct versions of documents while retrieving.
- Using Mirosoft MarkItDown to read PDF, Word, Excel, Powerpoint, CSV, HTML, JSON, XML documents and convert to markdown.
- Automatically splitting and indexing TXT, Markdown and 8 kinds of table layout of CSV.
- Well-defined text format for laws, regulations and other regu-like documents.
